### 🧑‍💻 Sobre mí

Desarrollo software de punta a punta: diseño la arquitectura, modelo las bases de datos (SQL y NoSQL), construyo las APIs y las interfaces, y llevo el sistema hasta producción. Además, transformo datos en información útil para la toma de decisiones mediante análisis y dashboards de **Business Intelligence**.

He trabajado en soluciones para el **sector salud**, la **gestión operativa empresarial**, el **soporte TI e infraestructura** y las **plataformas de educación virtual universitaria**.

- 🏗️ Arquitectura de software y diseño de bases de datos relacionales y NoSQL
- 🔌 Construcción y consumo de APIs REST documentadas (Swagger / OpenAPI)
- 📊 Análisis de datos y dashboards con Power BI, Excel y SQL
- 📱 Desarrollo de aplicaciones web y móviles escalables
- 🛠️ Soporte técnico N1/N2 en hardware, servidores y redes
- 🌱 Actualmente profundizando en: Cloud (AWS / GCP), contenedores y analítica de datos
